# Лаборатория Телемедицины - Система сравнительного анализа LLM для медицинских анализов

Система для автоматической обработки и анализа медицинских документов с использованием современных языковых моделей (LLM). Проект предназначен для сравнительного анализа эффективности различных AI-моделей при первичной интерпретации результатов медицинских анализов в рамках телемедицинских решений.

## 🎯 Цель проекта

Данный проект реализуется в рамках написания научной статьи на тему **"Сравнительный анализ эффективности современных LLM при первичной интерпретации результатов медицинских анализов"**. Система предназначена для внедрения в телемедицинские платформы в качестве функций для получения первичного фидбэка от ИИ при анализе медицинских анализов пациентов по запросу на сайте.

## 🚀 Основные возможности

### 🔒 Безопасность и деперсонализация
- **Автоматическая деперсонализация** медицинских документов (маскирование персональных данных)
- **Защита конфиденциальности** пациентов при обработке
- **Безопасная передача** данных в AI-сервисы

### 📊 Обработка документов
- **OCR-распознавание** текста с медицинских документов
- **Поддержка форматов**: PDF, JPG, PNG, TIFF, BMP
- **Автоматическое определение** ориентации изображений
- **Предобработка** для улучшения качества распознавания

### 🤖 AI-анализ медицинских данных
- **Мультимодельный анализ** с использованием ведущих LLM:
  - **DeepSeek AI** - структурированный анализ медицинских показателей
  - **GigaChat** - российская модель для медицинской интерпретации
  - **ChatGPT (OpenAI)** - анализ отклонений от референсных значений
  - **YandexGPT** - дополнительная модель для верификации
- **Автоматическое определение** отклонений от референсных значений
- **Структурированные результаты** в форматах JSON и TXT

### 🧠 Машинное обучение
- **Классификация медицинских документов** с помощью ResNet
- **Предобученные модели** для определения типа анализов
- **Автоматическое обучение** на новых данных

## 🏗️ Архитектура системы

### Основные модули

```
src/
├── main.py                    # 🎯 Главный модуль - точка входа
├── processor.py               # 🔧 Обработка и деперсонализация документов
├── deepseek_client.py         # 🤖 Клиент DeepSeek API
├── gigachat_client.py         # 🤖 Клиент GigaChat API
├── chatgpt_client.py          # 🤖 Клиент ChatGPT API
├── chatgpt_client_pdf.py      # 🤖 Клиент ChatGPT для PDF
├── yandex_gpt_client.py       # 🤖 Клиент YandexGPT API
├── predict_image.py           # 🧠 Классификация изображений
├── train_model.py             # 🧠 Обучение моделей
├── rotate_images.py           # 🔄 Поворот изображений
├── utils.py                   # 🛠️ Вспомогательные функции
└── names_cito_list.py         # 📋 Список медицинских терминов
```

### Кластеры функциональности

1. **📄 Кластер обработки документов**
   - `processor.py` - основной процессор документов
   - `utils.py` - утилиты для работы с Poppler
   - `rotate_images.py` - коррекция ориентации

2. **🤖 Кластер AI-анализа**
   - Все клиенты LLM (DeepSeek, GigaChat, ChatGPT, YandexGPT)
   - Асинхронная обработка запросов
   - Обработка ошибок и retry-логика

3. **🧠 Кластер машинного обучения**
   - `predict_image.py` - классификация изображений
   - `train_model.py` - обучение моделей
   - Использование предобученных ResNet моделей

4. **🎯 Кластер управления**
   - `main.py` - координация всех процессов
   - Логирование и мониторинг
   - Управление жизненным циклом

## 📦 Установка и настройка

### 1. Клонирование репозитория
```bash
git clone [url-репозитория]
cd telepat-laboratory-of-telemedicine
```

### 2. Создание виртуального окружения
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Установка Tesseract OCR

#### Windows
```bash
# Скачать с https://github.com/UB-Mannheim/tesseract/wiki
# Установить и добавить в PATH
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt-get update
sudo apt-get install tesseract-ocr tesseract-ocr-rus
```

#### macOS
```bash
brew install tesseract tesseract-lang
```

### 5. Настройка API ключей

#### GigaChat
Создайте файл `gigachat_config.txt`:
```
GIGACHAT_AUTH_KEY=ваш_ключ_здесь
GIGACHAT_SCOPE=GIGACHAT_API_PERS
```

#### Другие API
```bash
export DEEPSEEK_API_KEY="ваш_ключ_deepseek"
export OPENAI_API_KEY="ваш_ключ_openai"
```

## 🚀 Использование

### Базовое использование
```bash
python -m src.main
```

### Процесс обработки
1. **📥 Загрузка**: Поместите медицинские документы в `input/`
2. **🔒 Деперсонализация**: Автоматическое маскирование персональных данных
3. **🤖 AI-анализ**: Параллельная обработка всеми доступными LLM
4. **📊 Результаты**: Сохранение в соответствующих директориях
5. **📦 Архивирование**: Перемещение в `input/archive/`

### Результаты анализа
- **DeepSeek**: `ai-result/deepseek/` (структурированный JSON)
- **GigaChat**: `ai-result/gigachat/` (структурированный JSON)
- **ChatGPT**: `ai-result/chatgpt/` (текстовый анализ)
- **YandexGPT**: `ai-result/yandex/` (дополнительная верификация)
